# 在庫・貸出管理アプリ

レンタル・貸し借りが多い在庫を管理するためのシンプルな Web アプリです。
ビルド不要で、`index.html` をブラウザで開くだけで動きます（データはブラウザの localStorage に保存）。

## タブ構成

| タブ | 内容 |
| --- | --- |
| 📦 在庫 | 品目の登録・編集・削除、総数／貸出中／現在の在庫数、カテゴリ絞り込み・検索、次の予約表示 |
| 🔁 貸出・レンタル | レンタル（有料）・貸出（無料）・借用（他から借りる）の登録、返却処理、延滞・予約の管理、今月の売上 |
| 📅 カレンダー | 月表示で貸出期間を色分け表示（▶開始／■返却期限）、日付クリックでその日の貸出と在庫数を確認、その日から貸出登録 |

## 主な機能

- **期間ベースの在庫チェック**：予約登録時、その期間中の空き数を日ごとに計算し、在庫が足りない場合は保存できません（ダブルブッキング防止）
- **延滞の自動判定**：返却予定日を過ぎて未返却のものは「延滞」として赤で表示し、返却されるまで在庫を占有しているとみなします
- **料金の自動計算**：品目に1日あたりのレンタル料を設定しておくと、数量×日数で料金を自動入力します
- **借用の記録**：他から借りている物も管理でき、返し忘れを防げます（自分の在庫数には影響しません）

初回起動時はサンプルデータが入っています。不要なら各行の「削除」で消してください。
