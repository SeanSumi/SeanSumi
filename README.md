# カメラ貸出台帳

カメラの在庫・無料レンタル・借用・予約をチームで管理するアプリです。
パソコン（Windows / Mac）やスマホに「アプリとしてインストール」して使えます。Claude のアカウントは不要です。

公開・共有の手順は **[SETUP.md](SETUP.md)** を見てください。

## タブ

| タブ | 内容 |
| --- | --- |
| 在庫 | 製品ごとのカード。在庫数、今だれに貸しているか、次の予約、今後14日の貸出状況。カード右下の「在庫登録」で台数を増減 |
| 貸出・レンタル | 「誰が 誰に 何を 何台 いつまで」を1行で表示。状態・製品・担当者で絞り込み、返却処理、一覧のテキストコピー |
| カレンダー | 月表示。製品ごとに色分け、製品で絞り込み、日付を押すとその日の貸出と在庫 |
| 担当者 | 担当者ごとの貸出中・予約・延滞。担当者の追加・名前変更・並び替え・削除 |

## 主な機能

- 期間ごとの空き数チェックで、同じ製品の二重予約を防止
- 返却予定日を過ぎた未返却は「延滞」として赤で表示
- 操作の履歴を Google スプレッドシートの `history` シートに自動記録（管理者だけが見られる）
- 接続先が未設定のときは、そのパソコンの中だけで動く「お試しモード」

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | アプリ本体 |
| `config.js` | 共有データ（Apps Script）の接続先URL |

| `gas/Code.gs` | Google スプレッドシート側のプログラム（Apps Script に貼り付ける） |
